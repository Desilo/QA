## 목표
analyst가 Descriptive Statistics 알고리즘을 활용하여 분석을 수행행한다.

### Data-registry
1. data-registry에 provider로 로그인한 뒤 데이터 등록 페이지로 이동한다.
2. 파일 업로드, 이름, 설명을 채운 후 다음 스텝으로 이동한다.
3. 컬럼 정보는 건드리지 않고 등록 버튼을 눌러 데이터 에셋을 추가한다.

### Admin
4. admin에 admin으로 로그인한 뒤 “데이터 스페이스”로 이동한다.
5. 데이터 스페이스에서 “+” 버튼을 누른 후 이름을 입력하고 데이터 스페이스를 추가한다.
6. 생성한 데이터 스페이스 탭으로 들어가 “데이터 제공자 배정”을 클릭하고 “provider1”을 선택한 뒤 배정한다.
7. "데이터 에셋 추가" 버튼을 눌러 업로드한 hospital 파일을 추가한다.
8. "분석가 목록" 탭을 누른 뒤 "분석가 추가" 버튼을 눌러 "analyst6@gmail.com"을 그룹에 추가한다.

### Asker
9. asker에 analyst6로 로그인한 뒤 프로젝트 생성을 눌러 이름을 입력한 뒤 생성한다.
10. 워크플로우 생성 버튼을 눌러 Workflow Form으로 이동한다.
11. 새로 업로드한 main4 데이터를 기반으로 Descriptive Statistics 분석을을 실행한다.
12. 프로젝트 탭에서 결과를 확인한다.

```
STRATRA Column : provider1.MAIN.STATIN
COLUMN Column : provider1.MAIN.1E_LDL
```
